# Issue tracker: GitHub

Issues and PRDs live in GitHub Issues for `lastland/SpecMonad`.
Use the `gh` CLI, with `--repo lastland/SpecMonad` when needed.

## Conventions

- Read tickets with `gh issue view <number> --comments`.
- List tickets with `gh issue list`, filtering by state and labels.
- Publishing a spec or ticket means creating a GitHub issue.
- Require an explicit user request before creating or modifying issues or PRs.

## Pull requests as a triage surface

**PRs as a request surface: no.**
